# anxi-ssh-game

一个跑在 SSH 上的终端小游戏。`ssh 任意名字@主机 -p 8822` 连进去就是一个模拟终端。

## 特点

- **不需要密码**：任何用户名 + 任何密码都能进（这是游戏，不是真 shell）
- **没有真实能力**：所有命令都是假的，只打印预设文本，不碰文件系统
- **每个连接独立**：状态互不干扰

## 玩法

```
help        命令列表
status      查看服务状态
ls / cat    看假文件系统
ps / kill   看假进程，干掉 meetingd
repair      修东西（mood / focus / sleep）
restart     修好后重启服务
egg         彩蛋手账（6 个）
```

## 快速开始

```bash
npm install
./start.sh          # 启动（默认 8822）
./start.sh status   # 查看状态
./start.sh stop     # 停止
```

连接：

```bash
ssh guest@你的主机 -p 8822
```

## 配置

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | `8822` | 监听端口 |
| `HOST` | `0.0.0.0` | 监听地址 |
| `SSH_HOST_KEY_PATH` | `keys/host_key` | 主机私钥路径 |
| `SSH_HOST_KEY` | — | 直接给私钥内容（优先于路径） |
| `DEBUG` | — | 设为任意值打印客户端错误 |

## 主机密钥

`ssh2` 只认 OpenSSH 格式。首次启动会自动跑 `ssh-keygen -t ed25519` 生成到 `keys/host_key`。

**注意**：换密钥后客户端会报 host key 变了，需要 `ssh-keygen -R "[主机]:8822"` 清掉旧记录。

## 安全说明

这是一个**玩具**，不是远程终端：

- 没有真实 shell，`ls` / `cat` / `ps` 全是假输出
- 不读写任何真实文件
- 不执行任何系统命令
- 任何人都能登录（没有账号体系）

**不要把它当成生产环境的 SSH 服务。**

## 端口

默认 `8822`，避开标准 22 端口，减少被扫描器盯上的概率。

如果要对公网开放，记得在防火墙/安全组放行 `8822`。
